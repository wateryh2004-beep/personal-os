# 工作区内部细化 v2：验收记录

日期：2026-10-15。基线：`3b97ad1`。任务：在已发布的全局设计 v2 基础上，进一步优化职业、面试、笔记和日历内部，并建立易复制的 Agent 文档阅读指令。

范围与交互定义见 [规格](../specs/workspace-details-v2.md)；长期规则来自 [设计](../design-system.md)、[动效](../design/motion.md)、[交互](../design/interaction-clarity.md) 与 [质量](../quality-standards.md)。

## 已实施

- 职业首页：岗位卡片、面试时间与准备情况的层级；下一步独立布局；管理默认折叠，原有路由和实际数量保留。
- 面试阅读：16px/32px 正文节奏、衬线内容标题、持续可达的章节入口；自测收起答案与讲解，移入自测区，支持恢复原文。
- 笔记：摘要/列表切换、标题和元信息；正文阅读/编辑切换，保留同一编辑器与保存状态，阅读当前草稿。
- 日历：日期层级、手机可见的新建、有效筛选与清除；内联错误；月导航处理日历月、月末、跨年和 DST，事件时间契约不变。
- [Agent 使用指南](../agent-quickstart.md)，并从 AGENTS 与索引进入。界面任务不能只以公共样式迁移视为完成。

## 运行影响与恢复

无数据库迁移、凭据或环境变量变化；不改写生产个人经历、笔记正文或 Outlook 日程。新增浏览器脚本仅允许 localhost，对所有非 GET 请求阻断，API 由合成数据与失败边界提供。生产仍不可开启 `E2E_MOBILE_HARNESS`。

回退只需恢复先前应用部署；数据格式和外部写入管道未变化。当前实现分支不等于生产已发布。

## 验证边界

合成 Chromium 的布局、DOM 生命周期和交互结果不等同于真实 Apple/Windows/Android 字体、低端设备帧率、生产网络、真实账号恢复或完整业务写入验收；此任务不使用真实 owner 密码或数据做写入测试。
