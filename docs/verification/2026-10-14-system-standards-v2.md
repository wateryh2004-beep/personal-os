## 排查方法与边界

全量清点 `src` 中的 TypeScript、TSX 和 CSS，包括 61 个页面入口、50 个 API Route。静态扫描覆盖全部源文件；人工沿共享组件、认证、核心工作区、面试查询、草稿、保存、弹层和日志调用链追踪。全仓扫描不等于每行都已人工审计，更不等于真实设备或生产验收。

复现扫描：`node scripts/system-standards-audit.mjs --check --json=system-standards.json`。比较基线：增加 `--ref=00d7d05`。脚本只对明确的旧中性色、固定白色背景、小字工具类和 `transition-all` 阻断；控件命名列为人工追踪项，隐藏字段不被误报为可见表单缺陷。输出只包含路径、行号、规则和数量。

## 数据与权限复核

- 沿请求边界复核直接 owner 检查及被委托的 search、backlinks、tasks lists、各领域 assistant handler；不能用“Route 文件里没有 requireOwner 字符串”推断鉴权缺失。
- `/api/version` 仅公开构建版本。Microsoft Webhook 使用 subscription/clientState 校验后唤起服务端 delta pull，不能改成普通登录路由。Cron、OAuth、恢复流程维持原有独立认证边界。
- 新增闲暇重取复用 owner 校验、归档检查、关联笔记归属与 schema 解析，只返回反馈，不在客户端写入数据库。
- 未更改数据库 schema、RLS、生产密码、恢复答案、生产环境变量、原件和审计保留逻辑。生成类型包含结构，不包含表数据或凭据。

## 仍需明确区分的范围

1. 当前 public schema 类型先接入面试读取，不能据此声称全部 Supabase 调用都已有强类型契约。
2. 静态命名候选中，自定义 `Field` / `field()` 包装器与测试夹具需人工追踪；命名正确不等于全部键盘、朗读器和触控行为已验收。
3. 真实 Apple/Windows/Android 字体回退、低端移动设备帧率、200% 字体、完整暗色矩阵和真实生产网络延迟，需要实际设备证据。没有测量就不声称达到帧率或耗时目标。
4. 原生 ViewTransition 不支持的环境保留正常导航。共享侧栏和已延迟加载的 AI 面板已处理退出生命周期；后续新增入口仍需验证实际打开/关闭/重开，不能仅以公共样式存在宣称动画验收完成。
5. 此记录不宣称已配置生产告警、定时备份或新的服务目标；这些是运行配置任务，不能由代码排查伪造完成。
