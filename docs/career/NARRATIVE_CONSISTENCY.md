# Interview Lab · 统一叙事与答案一致性契约

状态：2026-10-21 第二轮开发候选；已写入迁移、只读审计与操作页面，尚未合并部署或应用数据库。
适用：Career 经历库、面试故事、母题与答案版本。遵循 [Career 四层边界](FOUR_LAYERS.md)、[学习契约](INTERVIEW_LEARNING.md) 和 [数据治理](../data-governance.md)。

## 权威与继承

1. **真实经历及其核对证据**是身份、职责、期间、成果、金额和规模的事实来源。 `experiences`、`experience_outputs` 中的历史描述是核查线索；未经证明的数字不可自动升级为 `experience_facts.document_verified`。
2. **个人故事**从事实中组织 STAR 叙事，保留个人/团队行动、已发生结果与待验证假设的界限。故事库不覆盖经历事实。
3. **Canonical Narrative（统一叙事母版）**组织一致的自我定位、能力主张、有限的代表故事和职业方向。它是可修改的表达权威，不是事实权威；草稿不得自动认定用户确认。
4. **问题母题**存提问意图和逻辑，不同问法可复用同一母题。其对应答案仍须回应具体问题。金融专业题、Case 不要求人为绑定个人故事。
5. **岗位版本**明确继承的母版版本、所选故事、岗位差异和禁用主张。岗位适配可以改变表达重点，不能改变既有事实。真实招聘/投递状态绝不从岗位准备推导。

## 答案写作与版本

- 面试官可直接听到的稿件属于 `answer_mode=spoken`；`framework` 只承载提纲，不替代口述答案。使用已有 `## 标准答案`、`## 思路拆解讲解` 阅读契约。
- 中文/英文内容必须语义与事实一致，英语段落保持自然口语，思路拆解有忠实中文对照与语境化词汇；双语同槽时注明只朗读一种语言。
- 新生成答案只能按 append-only 语义新增 **AI draft**；用户明确采纳之前不得设为 `current`、不得声称已掌握或确认，更不能静默覆盖旧版、简历冻结快照。
- 涉及事实变更时，相关答案进入**待重新审核**清单；未落地自动引用关系前，在答案讲解中注明母版版本标识和人工复核状态。
- 与具体岗位有关的说法区分“本人能力与求职动机”“招聘 JD 的真实要求”“当前招聘是否开放”。三者不可互相代替。

## 第一轮已执行 / 尚未实现

2026-10-21 对线上现有 14 个自我介绍岗位准备新增各一份 `spoken` 的 AI draft，并为通用自我介绍增加母版草稿。批次标记 `NARRATIVE_20261021_V1_TARGET` 与 `NARRATIVE_20261021_V1_MASTER`。没有自动采纳，也没有覆盖既有 framework、旧答案历史或招聘数据。改写优先使用可靠的职责、方法和项目事实；对公司名称、雇佣日期、平台规模、个人/团队归属冲突保持谨慎。

第一轮以讲解文本作引用说明，原本不具有数据库约束。**本次第二轮候选**新增：
- `interview_narratives`：从通用 `spoken` 答案明确选定一个基线版本，`review_status=draft` 不等于用户已确认。
- `interview_answer_narrative_links`：岗位口述答案版本与其引用的母版答案版本形成持久关联。数据库触发器核对跨表 owner、题目类型、上下文与版本归属，RLS 不允许跨用户读写。
- `interview_answer_fact_links`：为答案版本预留具体经历事实**版本**引用。当事实追加新版本时，审计可根据固定 ID 提示复核，而不是依赖模糊的文本相似度判断。
- `/career/interview/consistency`：按读时重算显示母版版本漂移、尚未引用、未审核和缺少事实绑定。人工改变母版基线不改写答案；未经复核不能自动将旧引用标记为已核验。
- 初次迁移仅从 `NARRATIVE_20261021_V1_MASTER/TARGET` 批次标识回填可核对的引用，全部标记 `unreviewed`，不修改原有答案正文、采纳状态、招聘或申请数据。

**能力边界**：这是结构性一致性审计，不是自动语义证明。没有事实版本绑定时不能识别自然语言中的所有时间、数字或个人贡献冲突；`linked` 只表示版本关系已经人工核对，不代表全文真实。读时重算不是后台定时任务或通知。该代码和 migration 仅为待测试/审查的 PR 候选，未在生产生效。

## 验收标准

- 统一自我介绍：1 份未采纳母版，14 个岗位分别有可口述稿，每个都有选择故事的理由、岗位差异与事实边界。
- 同一事实在多份答案中的期间、职责、项目成果互相兼容，未确认数值不出现为事实。
- 新稿仍为 AI draft；`current`、`confirmed_at`、申请状态、旧答案和旧故事均不因此改变。
- 在实现自动一致性检查前，人工审核包括身份事实、故事归属、中文/英文含义、待验证结果与岗位适配。
