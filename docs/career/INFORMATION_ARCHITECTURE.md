# Career 信息架构

> **当前生效版本（2026-10-20）**：Career 首页展示职业目标（`career_directions`）、真实招聘机会（`career_opportunities`）、投递记录（`career_applications`）及 Interview Lab（`interview_contexts`）四个互相独立的对象。主要导航是「职业目标／招聘机会／投递记录／面试准备」，其中旧的 92 个面试情境位于 `/career/interview/targets`；浏览器中最多三项“近期关注”迁到这里并用于情境置顶。**下列 2026-10-19 三入口与首页岗位展示描述仅用于保留历史决策，遇冲突以 [FOUR_LAYERS.md](FOUR_LAYERS.md) 为准**。不推断历史准备情境代表真实招聘，也不从准备行为推断已投递。

## 历史信息架构（2026-10-19，已被四层边界更新）

Career 的日常入口收敛为三个：目标岗位、面试学习、简历与经历。页面使用既有路由与数据，不增加聚合表、写入接口或另一套内容阅读器。

| 入口 | 路由 | 职责 |
| --- | --- | --- |
| 目标岗位 | `/career` | 先展示近期行动与继续阅读，再展示本人选择的近期关注岗位；其他目标默认折叠；职业资产统计和方向放在默认折叠的“职业资料与管理”中。 |
| 面试学习 | `/career/interview` | 复用主干题库、标准答案、独立讲解、来源与版本；从题目进入练习和复盘。 |
| 简历与经历 | `/career/experiences` | 通过“经历素材／简历版本”二级导航，分别查看真实经历与版本列表。此入口不承诺聚合所有关联文件。 |

机会与申请、路线图、技能、职业方向、证书、职业资本、职业档案和证明材料保留在“更多”。简历版本直接进入简历与经历分组，不再依赖“更多”。申请记录沿用机会与申请的二级导航。旧深链接保持有效，页面标题和菜单显示当前所在位置。

`/career/materials` 当前仍是既有文件列表，尚未按 Career 关联筛选；不把它升级成日常“我的材料”入口，也不新增覆盖二十类实体的聚合器。证明材料的关联筛选如确有需要，应单独提出可验收的范围。

Career 不复制 Today、Notes、Tasks、Calendar、Projects 或 Reviews 的底层系统。读取不计为练习或掌握；职业事实不被表达版本覆盖。无目标岗位时先进入通用题库，不提示尚未实现的 Agent 自动写入流程。

维护时先区分：入口和展示改 `career-nav.tsx` / `career-home-view.tsx`；读取改 `features/career/queries.ts`；学习内容展示复用 `interview-study-view.tsx` 与 `features/interview/study-content.ts`；内容修改继续使用明确的编辑/版本操作。每次只改一种用户行为，并在 PR 写出可观察的前后差异。

本次收敛替代 PR #57 的整包迁移思路。OAuth/MCP 网关、内容写入事务与 Notes 独立阅读页不属于此界面改动，需另行设计和验证。

## 2026-10-19 首页与简历工作区

- 首页不通过“2028”“占位”等标题文字推断岗位状态；最多三个近期关注由本人选择，按 owner 隔离保存在当前浏览器，只存 ID，不修改云端岗位或申请状态。浏览器无法保存时仍保留本页临时选择，并明确提示未持久保存。
- 原岗位读取从前三项扩大到最多 100 个，保留 priority、面试时间和 ID 稳定排序。其他目标用紧凑列表默认折叠。已有真实准备数量、日期和历史路线核对入口保留。
- 下一步按七天内面试、到期练习、已关注岗位的待安排准备、远期面试、路线计划排序；未安排练习不冒充逾期，远期占位目标不因存在题目而自动进入待办。日期仍按个人时区比较。
- 简历版本页使用 URL 中的 resume/q/status/direction 表示选中与筛选；草稿/定稿分别对应实际 draft/approved 状态。桌面左右布局，手机列表/详情切换，旧路径和记录 ID 保持有效。
- 详情复用既有 ResumeCard、CareerForm、Markdown、文件入口与 Server Actions；原文不裁减为摘要，嵌入标题降级以保持页面语义。已访问表单用 React Activity 保持实例，切换版本、筛选和浏览器返回不复制或丢弃内存草稿；关闭/刷新或点击链接离开时有未保存提醒。原件、定稿与投递引用不变。
- 策略材料依旧保留原记录与方向，可按方向筛选；本轮不按标题自动分类、迁移或改写记录。关注选择不跨设备同步；内存草稿不能跨刷新恢复。

验收范围见 [本轮记录](../verification/2026-10-19-career-workbench.md)。

## 2026-10-19 经历素材与详情（本地候选）

经历素材按组织、角色和真实日期呈现。搜索只匹配目录中的组织、角色、部门、地点与类别，不搜索事实或私密正文。类别、进行情况、确认状态可以组合；非进行中不代表已填写结束日期，确认状态不代表外部事实认证。URL中的q/type/period/status保留搜索输入空格和未知条件，进入详情、返回链接与刷新保留条件；返回地址只由固定内部路由生成。列表只向客户端发送元信息，不发送全库背景、原始记录或事实正文。

详情保持阅读优先，展示完整概况、可展开的原始记录、事实内容/数值/发生日期/备注、独立事实历史、成果描述与结果、表达来源/状态/方向和证明材料。历史时刻按个人时区显示，日期字段保留原DATE语义。成果外链只激活http/https。证明材料兼容经历与文档两种关联方向；不承诺尚未实现的材料下载入口。

列表、事实、成果、表达、关联、版本和证据按唯一ID稳定分页读取；读取失败显示资料可能不完整，不将失败当作空库或不存在。审计仍为最近最多20条，不冒充完整历史。显式读取重试使用router.refresh，因为现有客户端元信息不能修复服务端失败；搜索和筛选不刷新服务器。

新建经历、添加/修改事实、添加成果、创建表达、关联事实/批准、证据上传与归档沿用原CareerForm及Server Actions。界面重用共享Dialog：操作真实完成后才关闭，等待时禁止重复提交/关闭；失败保留字段和服务端验证反馈，不确定结果提示先核对记录。关闭、Esc、手机返回遇到未保存输入先给出继续编辑/放弃；真正放弃才卸载表单。归档需明确二次确认，保留事实、表达和冻结简历快照，沿用原归档语义；不新增恢复承诺。

阅读段落限制为约820px宽；输入16px，主要触控目标44px。动效沿用公共按钮、记录行、DisclosureSummary和Dialog的遮罩/主体/内容序列、焦点恢复与返回层；快速反向不使用页面计时器。关联与AI辅助在首次展开后才加载，随后通过React Activity保留输入并暂停隐藏内容的Effects。减少动态效果沿公共规则，本轮实际覆盖与限制见 [经历素材候选验收](../verification/2026-10-19-career-experiences.md)。无数据库迁移、依赖、生产配置或权限变化。

## 2026-10-19 目标岗位与岗位详情（本地候选）

首页保留“下一步／近期关注”的行动优先结构，近期关注卡片进入岗位详情，下一步仍可直接学习。原“其他目标”折叠列表替换为全部目标岗位目录，包含未归档的进行中、暂停和结束场景（不含通用场景）。组织、岗位与显示名称支持NFKC多词交集搜索，和真实状态组合；不根据年份或“占位”等文字推断状态。URL使用target_q/target_status，保留输入空格和未知条件；详情返回仅由固定内部地址生成。目录只传元信息，岗位及准备元信息按稳定ID分页读取，不再将100条上限当作全集。

详情归属目标岗位导航，先展示状态、语言、优先级与个人时区的面试时间，再展示岗位题目。完整备注默认折叠，使用共享Markdown阅读器并降级内嵌标题；题目区分已准备、到期、未安排和暂停，不将没有日期视作逾期。原题不可读的准备记录单独提示，不冒充可学习题目。暂停和结束岗位仍可查看题目，进入岗位学习前需由本人明确调整状态，不静默激活。

新建/编辑岗位、创建题目与从题库加入沿用原Server Actions，通过共享CareerForm与任务Dialog提供等待禁用、失败保留、Esc/手机返回的未保存确认、放弃与焦点恢复；失败核对入口指向岗位本身。关联方向/机会/申请ID与场景类型保持原值；加题不再只展示前8条，支持检索全部未加入的主问题。创建/加入原有成功跳转保留，并补充具体岗位路径失效。

面试时间以个人时区填写，服务端重新读取本人时区并转换UTC；未改动的时间保留原秒数和已有DST时刻，新选择的不存在/歧义时刻拒绝并保留字段。岗位准备状态不代表申请结果，也不在此自动创建任务或日程。显式读取失败重试采用router.refresh修复服务端树，搜索和筛选不刷新服务端；不再使用整页reload。

本轮复用公共按钮、记录行、DisclosureSummary和Dialog的动效及焦点/返回层；不增加动画定时器或另一套弹层机制。无migration、依赖、生产配置或权限变化。实现与本地合成验证边界见[目标岗位验收](../verification/2026-10-19-career-targets.md)。
