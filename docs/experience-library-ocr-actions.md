# 经验资料库：图片文字、来源与行动

本功能使用既有的浏览器本地 OCR。新图片封存并关联成功后依次尝试识别；详情页可批量识别旧图片、查看和修订识别文字。原图和原 OCR 保留，修订按图片和原件 SHA-256 追加版本；搜索优先使用当前原件的最新修订。重新识别、取消或失败不删除已保存的原件。OCR 可能有误，图片仍是权威来源。PNG、JPEG、静态 WebP 支持本机识别；GIF 和 AVIF 可保存但不能使用该 OCR。识别依赖当前浏览器和本站语言包，导航会停止，失败后可重试。

只有用户在图片详情中明确将该文件设为允许 AI 使用，AI 整理才会包含图片识别文字；敏感和禁止 AI 使用的文件不进入模型上下文。用户主动点击 AI 整理后，按预算截取实际发送的文字，服务端仅为其中逐字匹配的引文生成来源定位；未匹配项显示不可核对，旧来源在展示时重新核验。识别文本是派生内容，不代表模型查看了图片。

关联行动由用户在弹窗填写并确认后，通过现有 Microsoft To Do Server Action 创建。任务说明包含来源经验链接；任务创建确认后保存 owner-scoped 关联，详情页可回到任务。Microsoft To Do 为任务状态的权威。如果创建结果不明，界面要求先检查任务列表再重试；关联失败时只重试关联，不再次创建任务。

## 发布与恢复

部署前确认 `20261028073144_experience_library_v1`、`20261028123909_experience_library_notes_filters` 和本次 `experience_library_ocr_sources_actions` 迁移依次存在。新迁移添加两张强制 RLS 的 owner 表及筛选函数，先应用迁移再部署应用；不批量重写原图或历史记录。系统快照 schema v2 纳入备注历史、OCR 修订、任务关联和备注字段；旧快照需使用与其 schema 匹配的仓库版本验证。经验库 JSON 导出包含图片 OCR 文本、修订和任务关联，图片原件仍通过 Files 原件包恢复。

回退应用代码时保留新表与数据；旧代码不会展示新功能。不得通过删除修订或任务关联来回退。旧搜索函数可通过前一迁移的 `search_experience_library_v2` 定义恢复；恢复前先确认备份和受影响的筛选行为。真实 Microsoft To Do 写入与 AI 调用需由使用者主动确认并验收，不把模拟测试当作真实连接通过。
