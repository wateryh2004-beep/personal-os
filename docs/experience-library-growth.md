# 经验资料库：增长后的查找、归组、对照与复盘

本轮为私人经验库提供以下业务能力：

- 搜索由 owner-scoped `search_experience_library_v3` 分页，每页展示 20 条并额外读取一条判断是否有下一页；最多 500 页，超过上限时需缩小查询。已生效筛选在结果外可见并可逐项移除。标签集合完整分页读取，失败时不宣称结果完整。
- 小红书分享链接按帖子 ID 给出重复提示，其他链接保持精确来源匹配。相同标题仅产生候选提示，绝不自动合并。合并是可撤销的逻辑归组：原记录、原文、图片、OCR、备注、版本、审计、任务关联都保留原 ID。主记录集中显示和搜索子记录，旧链接仍可打开并指向主记录。子记录不可作为带子级的合并来源，数据库验证同一 owner 和无环目标。合并/拆分及审计处于一个事务。
- 对照页从列表选择两至三篇，由各自原文、来源、标签、用户判断、AI 摘要及图片链接组成。共同标签只表示分类相同，不冒充相同建议；不同原文不由算法自动判定矛盾。
- 关联任务仍以 Microsoft To Do 为执行权威。行动复盘在经验库追加独立版本，记录用户的结果标签和备注；任务完成状态不由复盘改写。写入以稳定 request ID 幂等，并在同一数据库事务内记审计。
- 90 天未复核仅提示用户重新检查日期和招聘流程，不自动标记过时。用户点“已核对内容”后更新复核时间并记审计；“已过时”继续由用户明确设置。

## 发布与回退

先在目标 Supabase 项目应用 `experience_library_discovery_review_merge` 迁移，再部署使用 v3 查询的应用代码。迁移只新增字段、函数和复盘表；没有原件复制或永久删除。系统快照 schema v3 和经验库 JSON 导出包括归组指针、复核时间和复盘历史；恢复旧快照需使用匹配的旧版本验证器。

回退应用代码时保留新字段与复盘表，禁止删除源记录或清空合并关系。旧代码无法聚合合并子记录；如需回退，应先通过 `undo_experience_library_merge` 逐个拆分，确认所有原记录重新出现在列表，再部署旧版。不要直接将归组指针清零而绕过审计。

## 验证范围

隔离 PostgreSQL 合成数据覆盖 80 篇分页、归组后的全文搜索、撤销、外用户拒绝、审计和复盘幂等。TS/组件测试覆盖候选预览、对照页面、复核提示和备份恢复。生产部署 READY、本地构建和模拟测试均不等于真实账户视觉验收。私有图片原件不会作为公开 URL 暴露；外部 Codex 或 Claude Code 需要经过授权的只读接口/工具取得字节，只有 OCR 文本时不能声称看过图片像素。
