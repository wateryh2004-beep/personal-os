# 动效与空间交互规范

状态：有效的目标规范。维护日期：2026-10-14。适用范围：所有具有动态反馈、状态切换与空间转换的界面。配合 [设计主规范](../design-system.md)；本文建立目标，不表示现有动画已迁移。

## 设计目标

采用积极、充分设计的运动：空间有前后，元素有来源，状态有衔接，动作有力度与停靠。可以使用纵深、形变、共享元素、层级错峰和适量物理回弹，形成接近用户期望的 Apple 式细节质量；不声称复现 Apple 的专有实现或参数。

简洁画面与丰富动态并存。优先设计真实对象的连续变化，避免为每个控件添加独立炫技。等待指示随真实等待存在，普通背景和装饰不持续循环。

## 每类动画的完整定义

组件或场景的规格至少写清：

1. **触发与真实状态**：由什么事件或服务结果触发，是否产生副作用。
2. **对象与几何**：来源、目标、锚点、尺寸、前后景、遮挡和 transform origin。
3. **时间线**：开始、衔接、结束；哪些并行、哪些有依赖；各阶段的节奏。
4. **运动质感**：路径、曲线/弹簧、加减速、停靠和必要回弹。
5. **中断与逆向**：连续点击、反向、切路由、返回、Esc、拖动和后台标签的处理。
6. **最终状态**：DOM、URL、焦点、可点击性、滚动与数据如何保持一致。
7. **替代与验证**：减少动态效果、低性能设备和动画被禁用时的完整操作。

同类组件共用模式与参数，只有确实不同的场景单独编排。不能只规定一个 duration 或添加 `transition-all` 作为设计完成。

## 节奏基准

以下是实施起点，需要真实设备与录屏验证；反馈延迟与动画总时长分别衡量。

| 层级 | 参考总时长 | 作用 |
| --- | --- | --- |
| 按下、焦点与选中 | 120–180ms | 即刻响应，轻微压缩/位移/颜色变化 |
| 局部状态、列表与展开 | 220–360ms | 让对象及周边重新排布 |
| 弹窗、侧栏与详情 | 320–480ms | 主体、遮罩和内容协调进入/退出 |
| 页面或大范围共享元素 | 480–720ms | 建立前进/返回与空间关系 |
| 登录成功的仪式性进入 | 850–1200ms，默认约 1000ms | 从认证空间连续进入工作空间 |

操作开始的可见反馈目标小于 100ms；长过渡不允许延迟点击响应或等待未知网络结果。进入和退出可以采用不同曲线，退出通常更直接。少量错峰用于层次，不能让长列表逐条等待。

按下可使用约 0.98–0.99 的局部尺度变化；纵深与大尺度变化主要用于场景/详情转换。保持文字清晰，避免全站每次 hover 都放大、晃动或模糊。

## 登录：进入自己的空间

| 阶段 | 动作与状态 |
| --- | --- |
| 输入 | 标签、光标、焦点边界协调，显示/隐藏密码不改变布局与焦点归属 |
| 提交 | 按下即反馈，按钮进入真实等待态，防重复提交；卡片保持稳定 |
| 已确认成功 | 服务端真实认证成功后，按钮给出完成反馈，准备共享的空间锚点 |
| 空间推进 | 卡片与前景按统一透视退场，背景及工作区由深处展开；保持可读参照，避免突然跳切 |
| 落定 | 真实受保护工作区接管，焦点/URL/滚动正常；数据未就绪时展示对应几何与真实加载状态 |

认证仍由服务端 session、受保护路由与 Supabase 管理。动画不提前授权，不预览未授权数据，不伪造登录成功。

过渡计时与动画事件解耦，动画被禁用、标签切到后台或事件未触发时仍能完成导航；保留可立即继续的可访问路径，不能让用户为动画受困。

## 找回密码：同一张卡片连续变化

问题、答案、新密码和完成状态共享卡片与对齐轴。卡片高度以真实内容为目标平滑改变，当前内容离场与下一步入场适度衔接；长错误不会越界或压住操作。

步骤前进与返回保持方向关系，返回保留可安全保留的答案输入。新步骤可操作后焦点进入首个相关字段，不等长动画结束才允许键盘工作。

填写答案后进入新密码步骤不表示身份已验证。最终提交在服务端验证答案和密码；成功场景只由真实更新结果触发。界面以“继续”“重置密码”等明确动作表达，无需展示实现过程，但不能使用“身份已验证”之类不真实的状态。

错误与成功在对应区域连续呈现；避免每次验证失败重新播放整张卡片的入场。秘密不进入截图、录屏或调试日志。

## 页面、卡片与详情

应用壳与导航保留空间参照。主导航同层切换采用一致语言；由列表进入详情保留来源锚点，关闭/返回沿关系收回；不能根据任意页面索引制造错误方向。

共享元素只复用真实来源与目标的必要几何，不通过复制整页私人 DOM 或持久化截图实现。不存在来源元素、直接打开详情或跨身份时使用可靠后备过渡。

内容刷新、排序、完成和删除时对象与周围布局一起协调；数据确认、乐观预览与失败回滚可区分。滚动与编辑器状态不因播放动画被重置。

## 控件与弹层

按钮覆盖静止、悬停、按下、忙碌、成功、失败与禁用。菜单/弹窗/侧栏的遮罩、主体与内容有协调节奏；焦点约束、Esc、外部点击和关闭后焦点恢复沿用成熟组件语义。

进度指示与真实任务绑定；进度未知时不伪造百分比。spinner、骨架和流式内容停止于实际任务结束或取消，不持续占用已关闭面板。

拖拽跟随输入，释放后停靠，取消回归可解释位置。触摸无 hover 时拥有同样的功能与完成反馈。

## 连续操作、性能与清理

用状态机或等价明确状态管理切换。反向操作从当前位置接续，取消旧计时器/监听/动画；旧请求结果不能安装到新页面或新 owner。

导航和数据请求与场景编排协调，不能等待动画结束才开始请求；失败显示真实结果。保持 Next 路由与浏览器历史语义，不用自建历史栈替换。

优先 transform/opacity 与有界几何过渡；避免全页布局抖动、每帧测量、长时间 `will-change`、过量 GPU 图层和不必要的大面积 blur。按需加载动画能力，不为低频场景拖慢所有页面。

动画库可在说明收益、依赖体积与维护成本后选择，原先“不得增加动效依赖”的旧限制不再作为全局禁止。仍复用共享实现，不能每个模块引入一套框架。

## 可访问替代与验收

尊重 `prefers-reduced-motion`：取消纵深、缩放和明显位移，采用即时状态或短淡入；保留状态、焦点与真实完成路径。动态偏好运行中改变时也应安全落定。

检查 390/1440px、触摸/键盘、快速重复与反向、返回、失败、长文本、后台标签、减少动态效果和组件卸载。录屏检查起始、中间、落定和中断，不能只凭成功态截图验收。

通过条件：空间关系可理解、每次输入立即有反馈、真实状态与画面一致、所有过渡可安全打断、没有焦点丢失/输入丢失/过渡锁死；对流畅度的线上声明须附测量条件。
