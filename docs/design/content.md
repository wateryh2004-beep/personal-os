# 界面文案与视觉引导

状态：有效规范。维护日期：2026-10-14。适用范围：导航、按钮、表单、状态、空态、提示与辅助说明。配合 [术语表](../glossary.md) 和 [设计规范](../design-system.md)。

## 原则

文字帮助识别任务、输入、动作和结果。位置与对齐表达关系，措辞保持中文优先、简短直接、同义同名。必要说明在需要时出现，不能用“极简”删除影响判断的事实。

默认移除装饰性英文眉题、私人空间标语、寄语、重复标题、重复步骤说明和不会改变用户判断的技术标注。内容自身的英文、作品名称、真实来源及专业术语按需要保留。

## 各类文案

| 类型 | 写法 |
| --- | --- |
| 页面标题 | 明确当前任务或对象；宋体层级由样式决定，不额外增加一句氛围文案 |
| 主动作 | 使用具体动词，必要时带对象：登录、继续、重置密码、保存修改 |
| 字段 | 稳定 label，格式/长度提示靠近字段；placeholder 只提供样式例子或短提示 |
| 等待 | 真实表达正在进行的动作；按钮内保持宽度，避免布局抖动 |
| 成功 | 只在真实完成后出现；说明必要结果与下一步，不重复庆祝性句子 |
| 失败 | 说清可公开的原因和恢复动作；避免泄漏账号存在性、内部堆栈和秘密 |
| 空态 | 区分没有内容、筛选无结果、未连接、不可用；提供一个相关主动作 |
| 已生效条件 | 当前筛选、日期、选中和未保存/失败状态可发现，不能藏在折叠内容里 |
| 辅助信息 | 低频来源/审计/实现细节按需展开；保留对象名称与必要摘要 |

## 认证入口例子

登录保留名称、必要标题、邮箱、密码、登录和找回入口。通过位置建立字段与找回关系，避免同时出现多层欢迎语、英文标注与底部寄语。

找回密码保留真实问题、两个答案字段、必要格式要求、主动作、返回与备用邮箱入口。新密码阶段仍未验证身份，不能标记“验证通过”。成功状态表达密码已更新；不向页面输出真实答案或校验值。

## 一致性与验证

更名同时核对导航、按钮、表单、空态、错误、可访问名称和相关测试。界面需要保留风险或结果说明时，优先简洁准确，不能用泛化免责声明占据主路径。

查看手机、长名称、200% 文字和实际错误场景；检查用户能否从第一眼判断当前对象、下一步和操作结果。删除一段文字前核对它是否承担必要标签、可访问说明、权限或失败恢复功能。
