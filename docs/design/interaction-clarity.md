# 全系统交互清晰度规则

目标：保留安静的视觉风格，同时让用户在不悬停、不试点的情况下判断「能做什么、会发生什么、现在是什么状态」。本批不是全站换皮；先建立公共约定，并迁移 Today、任务、笔记和面试学习的高频入口。

## 统一语义与组件

| 类型 | 默认可见线索 | 实现与约束 |
| --- | --- | --- |
| 主动作 | 动词＋对象、强调色按钮 | Button default；同一局部流程有明确主动作 |
| 次动作 | 动词＋对象、轻底色/可辨边界 | Button outline/secondary 或 ui-action-secondary；不用普通段落充当入口 |
| 文内链接 | 下划线＋链接色 | ui-link；不能只在 hover 后才可识别 |
| 可打开记录 | 连贯行级点击区＋方向线索 | ui-record-link；不要给纯展示文本同样提示 |
| 展开内容 | 标题＋展开/收起＋上下方向 | DisclosureSummary 用于原生 details；DisclosureTrigger 用于受控面板，调用者提供 aria-controls，并管理隐藏内容的 inert/aria-hidden |
| 新增/选择 | 加号配具体动作名称 | 加号不再兼任展开状态；删除/高风险动作继续收在菜单中 |
| 已选对象 | 背景之外的稳定标记 | ui-navigation-item + aria-current；ui-selectable-row + data-selected/aria-current，强制颜色模式提供轮廓 |
| 表单字段 | 独立标签、可见边界、焦点圈 | Input/Textarea/Select 或 ui-field；placeholder 不能替代标签；不要把阅读态和编辑态混为一谈 |
| 行级更多 | 默认可见、可聚焦、忙碌时禁用 | ui-more-action；不能靠 hover 才出现，也不能盖住文本 |

已有 Tailwind utilities 被分层；globals.css 的通用边框重置未分层。因此公共控件边界使用同样未分层的窄选择器（按钮使用稳定的 data-ui-button，避免 Radix asChild 覆盖 data-slot），不依赖会被重置覆盖的工具类。不要用全站强化分隔线来代替控件边界。

Today 只覆盖语义颜色变量，继续使用暖色、单一阅读面和轻分隔；同时覆盖 hover 颜色，确保暗色模式不会继承浅色控件背景。不要给所有内容增加卡片或颜色。

## 信息显示规则

必须露出：当前页面/选中对象、有效筛选、关键日期/状态、当前主动作、常用操作入口、影响判断的失败与保存结果。

可收起：来源版本、历史、低频设置、补充解释。收起时保留对象名称、必要数量和显式展开动作。高级筛选可以收起，但已生效的筛选与清除入口仍在外面。

面试学习继续「标准答案在前，讲解可展开」，保留完整原文、条件口径、答案来源，阅读不等于掌握。任务和笔记的低频动作继续留在更多菜单，不平铺全部功能。

## 可读性、触控与键盘

- 控件边界与预期相邻表面的设计对比度至少 3:1，本批有色值回归测试；最终仍以浏览器实际计算颜色与状态为准
- 手机/粗指针共享按钮、单行字段和图标控件至少 44px；桌面允许紧凑布局，不能裁掉焦点圈
- 原生 button/summary 承担键盘行为；触控无 hover 也能发现入口
- 弹层取消/Escape 后回到启动入口；保存导致原入口替换时回到同一区域的新入口
- 正文不因极简而过小过淡；长文字换行，关键日期不被截断；200% 字体下仍可到达操作
- 使用色彩以外的状态线索；保留 reduced-motion 与 forced-colors 支持

## 本批迁移范围

公共 Button/Input/Textarea/Select 的边界与移动触控下限；新增共享 disclosure 和可复用动作/链接/选中状态样式。Today 的选择重点、展开、未来记录和继续上次入口；任务/笔记更多菜单；任务日期/优先级字段与选中行；题库筛选摘要、明确导航选中态、章节操作、原题与讲解展开。

未改变数据、权限、认证、依赖、预取或查询。未宣称全系统每一页已审计；后续页面应逐步采用相同规则，避免再自行消除功能线索。

## 回归矩阵

| 路径 | 自动检查 | 发布前浏览器检查 |
| --- | --- | --- |
| Today 选择重点→取消/保存 | 弹层、取消不写、失败保留、返回焦点 | 390/1440、暗色 hover、短屏、触控 |
| 展开剩余→收起→重复操作 | aria-expanded/controls、inert、内容保留 | Enter/Space、状态文案、无横向溢出 |
| 任务/笔记→更多 | 默认可见源码约束 | 鼠标不悬停时可见、44px触控、禁用态、文本不被覆盖 |
| 题库筛选→收起→清除 | 有效筛选在 details 外、清除后恢复结果 | 手机/桌面、真实边框色、返回列表/浏览器前进后退 |
| 标准答案→讲解→收起 | 原文完整、答案先显示、重复展开不改答案 | 键盘 summary、长题目、200% 字体 |
| 导航/记录选择 | 每次只有一个当前目的地 | 非颜色选中标记、焦点可见、强制颜色模式 |

`tests/ui-affordance.test.ts` 覆盖组件与样式契约；`tests/ui-affordance-cascade.test.ts` 编译 Tailwind 后检查真实分层优先级；现有 Today、Interview 交互测试继续覆盖保存/取消、Back/Forward 和原文保护。

`scripts/ui-affordance-e2e.cjs` 只使用 E2E_MOBILE_HARNESS 门控合成场景，拦截写请求、API 和预取。CI 输出 10 张视口截图及简短证据，总体积断言小于 32 MiB。真实账户数据不会进入截图。

本地浏览器执行受环境限制，未运行或重试。CI 脚本已准备但未发布/触发；不可将静态检查或脚本存在当作视觉验收通过。发布前必须实际运行并检查产物。

衡量是否更方便：相同任务改造前后比较首次找到入口、误点、来回查找次数和完成步骤/时间。没有真实测量前不声称效率改善百分比。
