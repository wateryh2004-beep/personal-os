# 经验阅读版与待删除标记

一次原文粘贴对应一篇可阅读文档，仍归属于原经验记录。文档以 Markdown 保存，记录原文/图片 OCR 的逐字来源引用、覆盖状态、人工价值判断和修订版本。原帖文字、评论、私有图片原件、OCR 及已有用户备注继续各自保留。阅读版默认显示在详情页前部；复杂原帖与图片通过明确的“查看原文与图片”入口展开，来源链接会打开对应记录。

`quality_status=pending_delete` 只标记低价值候选，必须写明理由；页面默认收起这些文档，可用“保留这篇”追加新版本恢复。没有数据库删除操作。OCR 未完成或明显误读时将 `coverage_status=partial`，不能填入未读取的图像事实；图片仍由私有文件原件保存。文档引用在写入时由 owner-scoped RPC 验证与原文/OCR 逐字匹配，展示时再次核验，失效引用不冒充有效来源。

2026-10-29 初次整理覆盖生产库当前 9 次原文粘贴：6 篇保留、3 篇待删除、2 篇部分覆盖。初次文档由 Agent 逐篇基于原文与已完成的 OCR 人工整理，不自动向第三方模型发送私有图片。三张尚未 OCR 的旧图片仍待按需识别。当前没有配置经验库 AI Provider；新收录内容会显示“尚无阅读版”，需要后续整理，不能声称自动生成。

## 权限、备份与发布

`experience_library_reading_documents` 和 `experience_library_reading_versions` 均启用强制 RLS。保存 RPC 验证 owner、capture 归属、引用、版本和待删除理由，在一个事务中完成当前版、旧版与审计。JSON 导出及系统快照 schema v4 纳入文档及其历史；用户原图仍通过 Files 原件包迁移。

先应用 `experience_library_reading_documents` 迁移，再运行当前数据的逐篇整理，最后部署阅读界面。回退界面代码时保留新表和初次文档；不得清空原记录、版本、图片或待删除理由。旧快照请使用与其 schema 匹配的仓库版本验证。
