# 职业、笔记与日历：工作区内部细化 v2

状态：已采纳，实施与验收分别记录。日期：2026-10-15。基线：`3b97ad1`，即 PR #68 发布后的主干。遵循 [设计](../design-system.md)、[交互](../design/interaction-clarity.md)、[文案](../design/content.md)、[动效](../design/motion.md) 与各模块契约。

## 问题与用户结果

此前的全局迁移统一了视觉语言和若干基础交互；这些工作不能代替逐页设计。本轮直接细化三个高频工作区及面试内容页，不把全局 class 替换数量作为完成标准。

| 流程 | 基线问题 | 本轮结果 |
| --- | --- | --- |
| Career 岗位准备 | 岗位、准备情况和下一步均为轻小字行，重点与任务关系偏弱 | 一个岗位对应一张轻卡片；组织、岗位、实际准备数量与面试日期有清晰层级；下一步独立成组，管理仍默认折叠 |
| 面试学习 | 长答案与讲解层级偏小，自测需要手动避开答案 | 放大正文与标题，章节入口可持续访问；自测收起答案和讲解并移入自测区，可原样恢复答案，不记为练习或掌握 |
| Notes 列表 | 正常浏览只有标题和位置，需要逐篇打开才知道内容 | 默认显示已有摘要；可切换紧凑列表，搜索仍保留命中摘要，元信息包含位置与编辑时间 |
| Notes 正文 | 标题与操作挤在一行，持续显示编辑工具不利于阅读 | 独立标题与操作轴；同一文档内切换编辑/阅读，阅读当前草稿，CodeMirror 保持挂载，保存与冲突反馈持续可见 |
| Calendar 日期与操作 | 日期、视图与动作拥挤；手机新建藏在更多；月箭头按天移动 | 日期单独成视觉锚点，日期导航、视图与分类各有位置；手机直接新建；月导航按日历月移动并处理月末/跨年 |
| Calendar 筛选与失败 | 分类缺少统一清除；错误浮在固定坐标可能压住控件 | 有效筛选与清除显示在外部；错误在正常布局中显示；原有同步、编辑与确认路径保留 |

## 交互与数据边界

- 页面修改使用既有读取结果、路由、Server Actions 和共享控件。不增加数据库迁移、外部权限、环境变量或自动写入。
- Career 准备数量来自实际 preparation 状态，不虚构完成度或掌握率；真实经历、答案原文、版本、来源和解释完整保留。
- “自测与追问”只改变显示与焦点；正式练习仍从原有练习入口进入。切换题目由既有 keyed 实例重置阅读状态。
- 笔记阅读显示当前内存中的正文，可能包含尚未保存的修改；同一保存状态持续可见。切换模式本身不调用保存，既有防抖/手动/离开保存策略继续生效。隐藏编辑器不销毁其选择、滚动和撤销状态。
- 摘要使用已有 excerpt，不在浏览时调用 AI 或额外读取全部正文。摘要模式按真实行高布局，避免历史滚动恢复被离屏估算高度截断；紧凑列表保留既有离屏布局优化。
- Calendar 月移动属于显示游标，按用户 IANA 时区计算目标月，月末夹到有效日期，并锚在当地中午；事件时间的歧义/不存在规则仍拒绝转换。事件与 Graph 写入不经过显示游标转换。
- 日历保持同一 FullCalendar 实例，切换范围和筛选沿既有缓存与请求所有权逻辑；不重新挂载来播放过渡。

## 动效定义

| 对象 | 触发与轨迹 | 中断、返回与替代 |
| --- | --- | --- |
| 岗位卡片 | hover/focus 保持卡片几何，以边界、轻阴影和箭头 2px 方向响应；沿共享快速曲线落定 | 离开或移焦立即反向；无整页缩放；减少动态效果取消位移与过渡 |
| 标准答案 | 显示时 300ms，由下方 8px 与透明度 0 共同落定；答案隐藏后不参与可访问树 | 收起立即结束当前入场；再次显示从可靠起点开始，不延迟按钮操作；减少动态效果即时显示 |
| 笔记阅读 | 点击后立即切换可操作内容，300ms 8px/透明度入场；隐藏的 CodeMirror 继续存活 | 快速切换直接以最新模式为准，无计时锁；返回编辑保留实例；减少动态效果无位移/入场 |
| 日历范围 | 导航立即更新游标，保留日历空间与既有事件范围缓存；新建/编辑沿共享 Inspector 运动 | 迟到范围响应沿既有所有权规则拒绝；焦点、Esc、取消与 reduced-motion 复用共享实现 |

## 验收与排除项

检查 360/390/768/1440px、短屏、长标题、文字放大、键盘、快速返回/切换和 reduced-motion。验证岗位路由和真实数量、自测收回/恢复、列表显示切换、编辑器实例保留、月末/DST/跨年、手机新建与筛选清除。

浏览器使用显式门控的合成场景，拦截私有 API 和写请求，不使用生产密码、真实笔记或真实 Outlook 写入。截图与独立连续录屏分别采集；当前结果见 [验收记录](../verification/2026-10-15-workspace-details-v2.md)。不把合成 Chromium 当作真实设备帧率或生产数据验收。
