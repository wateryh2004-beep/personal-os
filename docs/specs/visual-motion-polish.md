## 视觉方向与边界

沿用暖白 `--surface-app` / `--surface-canvas`、深灰绿 `--accent`、既有主次文字与边界语义变量。宋体承担笔记标题、阅读章节与日期的视觉重点，系统无衬线承担正文与操作。通过一个明确阅读轴、任务主次和可解释的空间变化提高精致感，不增加装饰性常驻动画、第三方字体或动效依赖。

本轮只改变现有界面的展示和操作反馈：不增加数据库迁移、生产配置、外部权限或业务权威源，不扩大 AI 输入或主动执行 Microsoft 写入。Markdown、私有原件、版本、确认管道、身份边界及 owner 清理保持原有契约。合成验证场景不是生产数据或生产认证证据。

## 十项交付与运动定义

| # | 改进与真实入口 | 几何、节奏与最终状态 | 中断、返回与替代 |
| --- | --- | --- | --- |
| 1 | 笔记列表打开文稿、详情返回列表 | 列表行与真实文稿的非交互纸面按 note ID 配对，标题在同一阅读轴衔接。纸面与标题几何参考 620ms，旧纸面 180ms 退出、新纸面 420ms 淡入。只存/读取必要几何，不复制正文 DOM 或持久化截图。 | 原生 ViewTransition 只命名非交互纸面与标题呈现层；输入、返回和模式按钮留在 live 层，出现后立即可点。快速反向从当前状态接续；直接进入或不支持原生 API 时正常显示，返回保持列表位置。参考区禁用路由共享名，避免同笔记双区重名。减少动态效果取消空间运动。 |
| 2 | 笔记阅读、编辑与格式工具 | 标题、正文共用约 760px 文稿轴；正文通常 16px、行高 1.95。章节、引用、代码、表格与图片建立统一节奏，窄屏表格/代码在所属内容区域滚动。阅读方式控件以约 300ms 选中面移动表达切换。 | 保留同一个 CodeMirror、草稿、光标与真实保存状态；模式切换不触发整页刷新。标题静态呈现不重复朗读，不遮挡实际输入；输入聚焦后真实文字与光标接管。减少动态效果即时切换。 |
| 3 | 今日首页 | 使用真实快照日期的日期锚点，当前重点为主栏，日程、继续工作与后续上下文为副栏。容器足够宽时双栏，窄参考区及手机自然单栏，重点先于日程。首进分组编排沿用一次性日期标记；局部确认更新只对存留行执行约 300ms 重排。 | 同日返回不重播入场；日期标记不含业务正文。错误与更新不清空已有内容，实时偏好改变取消正在运行的行运动。手机保持原主动作与 44px 目标。 |
| 4 | 全局导航与侧栏 | 复用唯一 navigation registry，根据有明确含义的主导航顺序给声明的前进/返回切换赋方向；导航选中底面有稳定强调线。既有选中约 340ms、侧栏与内容宽度约 360ms 协调；非交互空间背景约 540ms 衔接，live 主内容以约 360ms、上下 12px 位移接入。 | 未知路径、同模块详情及浏览器未声明方向采用中性后备，不自建历史栈。最新路由为准，pending 与 `aria-current` 区分；原生名称仅给背景，live 内容可在途中立即响应点击。减少动态效果移除位移，强制颜色保留轮廓。 |
| 5 | 顶栏搜索 / CmdK | 保留来自真实入口的展开；搜索输入与结果列表常驻打开周期。显式“预览所选”后才展开只读参考区，桌面旁列、手机上下分区；面板宽度约 360ms、预览约 280ms 进入，键盘选中高亮约 180ms 移动。 | 查询、选择与导航保持清楚语义。手机有原生“预览内容”选择器和 44px 按钮，不要求 hover/键盘。预览内 Esc 先收起预览并返回预览启动点，再关闭搜索回真实入口；切查询/关闭卸载旧 reader，不启动编辑器或自动保存。受保护读取复用有界 owner 资源；身份失败清理私人状态。 |
| 6 | 工作台打开参考区、交换位置与调整宽度 | 保留两侧真实实体、编辑器及数值位置。分隔手柄跟随指针即时调整 30%–65% 参考区宽度，显示实际比例；键盘方向键、Home/End 及交换采用约 360ms 有界几何衔接。 | 取消指针、Esc、关闭、切手机和卸载释放捕获与拖动状态；Esc 恢复本次手势起始比例。连续交换取消旧动画并从现有几何接续，不能重建编辑器或丢草稿/PDF 页码。手机沿用主区/参考区切换，重型阅读器按外层活动状态暂停。 |
| 7 | 日历待安排任务拖入时间格、日程拖动/缩放 | 独立拖动柄呈现抬起的预览实体、真实 45 分钟初始时长和已载入日程的重叠提示；时间格沿用 15 分钟吸附。松开后进入既有可修改/确认流程，日程变更展示原/新安排、时区和已知冲突。取消回位约 180ms。 | 拖动源没有 click 写入或第二次打开副作用，手机/键盘使用独立“安排”按钮。重叠仅是已载入/最近同步数据的提示，加载中或截断范围明确说明；确认前无 Outlook 写入，失败保留预览。保持单一 FullCalendar，运行中减少动态效果取消回位运动。 |
| 8 | 项目页状态筛选、目标展开与参考入口 | 使用真实 active/completed 等状态与到期日期组织轻卡片和数量；推进→完成仅表达可核对的生命周期，暂停/取消独立显示。目标展开以约 360ms 高度/180ms 透明度协调，真实 props 确认完成后路径约 420ms 推进。 | 当前模型没有独立项目阶段/里程碑、自动下一任务或状态写入入口，本轮不伪造百分比、里程碑或成功。展开内容保持挂载、关闭时 inert，快速反向保留输入/内容；未知状态如实显示。现有速览、关联、参考区入口保持可用。 |
| 9 | Files 图片/PDF 预览、文稿中的 PDF 页签 | 从真实缩略图/行的有限矩形展开到现有 Dialog；桌面约 460ms 展开、240ms 收回，手机由底部接入。图片保持比例；按当前筛选与排序形成可预览文件队列，通过“上一文件/下一文件”及非输入区左右键在同一个 Dialog 中连续切换。PDF 在读取/绘制前后保留工具栏 DOM 和真实纸张比例占位，50%/适合宽度/200% 的纸面宽高跟随实际画布，画布真实完成后约 240ms 呈现。 | Radix 管焦点与退出 Presence；快速重开使用当前视觉状态。连续切换保留同一查看器外壳与可达的 44px 切换控件，旧 PDF 会话随文档切换销毁；关闭恢复最初启动点焦点。退出几何更新到当前可见来源，无可见来源时使用中性后备。关闭立即暂停 PDF，不请求下载原件；同文稿正文/PDF 页签保持已访问暖会话，外层 inactive/owner 变更/离开才销毁代理。减少动态效果取消缩放与位移；失败保留真实错误与恢复入口。 |
| 10 | 公共按钮、菜单、Popover、就地反馈 | 共享按钮按下约 140ms、0.985 局部尺度；颜色/边界约 160ms。菜单与 Popover 约 260ms 到位、160ms 收回，保留既有遮罩、焦点、禁用及忙碌状态。 | CSS 从当前帧反向，退出内容不可点击；减少动态效果运行中立即落定。保存/创建/完成状态只来自既有可信返回，失败保留输入和就地错误，不因动效伪造成功或重载页面。 |
