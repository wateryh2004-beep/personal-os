# Notes P3.4 — 轻量写作专注模式

状态：代码已提交候选 PR，实际多端验收以 CI/PR 结果为准。

- 编辑器的「专注」现在只将现有 NoteEditor 浮至全视口，不再要求浏览器原生 Fullscreen。
- 仍是同一个 CodeMirror，正文、草稿、标题、修订号、Undo/Redo、选区及滚动状态不会重建；阅读态入专注会切换至编辑态。
- 专注期间只显示标题、正文、保存状态、立即保存和退出专注按钮；隐藏侧栏、次要操作和 AI 面板，不影响外部数据。
- Escape 或退出按钮可关闭；退出后原工作区恢复、聚焦到启动入口。原生浏览器全屏作为「更多 → 进入浏览器全屏」保留。
- 不增加数据库、Markdown 解析器或第三方动效依赖。真实键盘、软键盘、浏览器缩放、短屏和 360/390/768/1440 视口的交互/视觉验收仍需验证。
