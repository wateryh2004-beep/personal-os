# 登录、找回密码与 Today 的设计 v2 迁移规格

类型：功能规格。日期：2026-10-14。状态：本分支已实现并进行分层验证；生产与真实设备验收另行记录。本文规定目标，实际覆盖与结果见文末实现记录。

## 目标与范围

依据 [已采纳决策](../decisions/2026-10-14-design-and-governance.md)，用共享基础、认证流程与一个日常工作区验证暖白、深灰绿、轻卡片、宋体标题和积极空间动效，随后作为全站复用样板。

包含共享变量/字体/控件、登录与成功进入、答题/邮箱找回、新密码及 Today 的布局与状态衔接。保持当前认证、限流、用户数据、权威来源、导航历史与外部确认边界。

## 数据与安全不变量

登录成功必须来自真实服务端结果。找回答案和密码只在必要流程内处理，不进入日志、录屏、URL、浏览器持久化或文档。进入密码步骤不表示答案已验证；最终验证/重置成功才显示成功。

不更改真实 owner 密码验收，不更换生产恢复凭据，不放宽 Preview 的答题恢复限制。使用既有合成 Auth/浏览器场景，真实 SDK 验证使用受控独立服务和精确测试账户。

Today 引用已有任务/日程与读模型，不改变执行权威。私有读取继续经过 owner 边界，跨身份清除资源；缓存、乐观状态与数据已确认分别表达。

## 界面与运动

| 场景 | 目标行为 |
| --- | --- |
| 登录初始 | 单一轻卡片，必要字段与动作，共同对齐轴；删除英文装饰、寄语和重复说明 |
| 提交与失败 | 按下立即反馈、真实等待、防重复；失败保留可安全保留输入并定位错误 |
| 登录成功 | 按钮确认 → 卡片/前景空间推进 → 受保护工作区展开；约 1 秒，可立即继续且不依赖 animationend 授权/导航 |
| 找回步骤 | 同卡片变形，内容与焦点衔接；返回与连续操作自然接续，邮箱备用入口可达 |
| 密码更新成功 | 真实更新结果 → 完成反馈 → 明确返回登录路径；不虚构其他已执行操作 |
| Today | 层级突出当前行动，卡片按任务组组织，保留日程/任务操作、继续入口和真实加载/失败状态 |
| 减少动态效果 | 取消明显纵深/位移，保留完整状态、焦点与导航路径 |

字体/色值/尺寸为 [设计规范](../design-system.md) 的实施基准；曲线、空间参数和可中断时间线按 [动效规范](../design/motion.md) 在样板中验证。

## 验收矩阵

| 场景 | 需要的证据 |
| --- | --- |
| 正常登录、错误、等待、成功进入 | 合成真实事件 + cookie/服务端成功边界 + 完整录屏 |
| 答案步骤、返回、新密码、错误、最终成功 | 输入/焦点/服务端状态一致；无前端假验证 |
| 邮箱找回与重置链接 | 不泄漏账户存在性，链接/会话/失败路径保留 |
| Today 加载、空态、长文、失败与操作 | 权威数据与任务关系保持，缓存与草稿不丢失 |
| 手机/桌面/短屏/键盘/200% 文字 | 390/1440px 为基本，布局变化补 360/768px |
| 动画中断、反向、后台与减少动态效果 | 无锁死、焦点丢失、旧请求覆盖或延迟开始请求 |

不把新规范的数值写入测试来替代行为验收。截图与录屏只用合成或已授权展示数据；真实用户设备和网络性能另行测量。

## 发布与恢复

预计不需要新的业务 schema 或恢复秘密；若实现发现需要，先更新此规格和相关运行说明。按 [质量](../quality-standards.md) 与 [发布手册](../release-operations.md) 选择检查，保留兼容回退，不通过恢复旧视觉代码删除新增业务数据。
