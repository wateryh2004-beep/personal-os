# 笔记切换与章节定位 · 第二批

状态：2026-10-25 实现规格。沿用 [设计](../design-system.md)、[交互](../design/interaction-clarity.md)、[动效](../design/motion.md)、[工程](../engineering-standards.md) 与 [质量](../quality-standards.md)；结果见 [验收记录](../verification/2026-10-25-notes-navigation-v2.md)。

## 范围与行为

- 快速打开沿用已授权的导航元数据和原有 60 条上限，不增加正文读取。输入中按上下键进入首/末条，结果内上下键、Home/End 移动真实链接焦点，首条向上回输入框；Enter 打开，Esc 清空并回输入。保留原生链接和新标签打开语义，只有实际客户端导航才清空搜索并关闭抽屉。中文输入法组合期间不处理这些导航键。
- 手机文档位置栏提供文件导航入口，可直接搜索和切换笔记；打开/取消抽屉不卸载当前编辑器、不替换草稿。沿用现有 Sheet 的遮罩、退出、焦点与触摸语义。
- 编辑器目录复用 Popover，支持标题关键词筛选、结果数量、无匹配/无标题状态、清空筛选、方向键与 Enter。按原始标题索引区分重名章节，跳转前重新核对当前编辑器文档；正文变动导致目标消失时更新列表，不跳到错误位置。
- 目录仅打开后解析，沿用 160ms 输入空闲更新。当前章节根据真实滚动视口测量，在 CodeMirror requestMeasure 中读布局、写标记；过滤不修改源索引。跳转关闭后焦点进入编辑器；Esc/关闭按钮回触发器，外点尊重目标焦点。关闭后重新打开清空筛选。

## 运动与可访问性

目录以工具栏按钮为锚，由 Radix 碰撞定位决定上下与 transform origin；主体从 6px 偏移、0.96 尺度到真实尺寸，320ms emphasized 曲线，透明度 160ms 并行。关闭反向 180ms；CSS transition 从当前帧接续快速反向，Presence 仅延续退出 DOM，不延迟输入/跳转/路由。退出不可点击，卸载由组件清理。减少动态效果去掉尺度/位移并即时落定；运行中改变偏好同样有效。无装饰循环或网络等待。

手机输入至少 16px，主要点击区至少 44px；长章节换行，列表有界滚动，短屏按 Popover 可用高度约束。保留可见焦点、键盘、触摸、强制颜色与 200% 放大路径。
