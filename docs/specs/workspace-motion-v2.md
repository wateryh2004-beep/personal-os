# 笔记与公共导航动效 · 第一批

状态：已实施，本地截图与连续录屏完成；补充环境验证未覆盖项见 [验收记录](../verification/2026-10-25-workspace-motion-v2.md)。日期：2026-10-24。范围由所有者确认：笔记排版、列表/详情过渡、全局导航与搜索弹层；不改变业务写入、认证、AI、数据权限或生产发布状态。

后续缩放/减少动态效果、测试环境修复与实际发布状态见 [补充记录](../verification/2026-10-25-workspace-release.md)。短视口详情允许文档位置及工具栏滚动离开，保持正文 320px 高度；不卸载编辑器或修改草稿。

## 视觉与结构

沿用设计 v2：暖白 `--surface-app` / `--surface-canvas`、深灰绿 `--accent`、主次文字与分隔语义变量。页标题宋体，正文系统无衬线，标题 30/36px，正文 15–16px。笔记导航保留默认 272px，保留用户已保存宽度与拖动；列表正文最大 840px，页头、搜索、记录共用对齐轴，减少空状态占位。全局搜索、导航快速打开与笔记全文搜索保留各自职责和名称。

主动作仍可发现，手机目标至少 44px。共享搜索容器常驻其打开/退出周期，重模块只在打开后加载；输入框、等待区和结果列表按同一面板组织。

## 完整运动定义

| 场景 | 触发、对象与几何 | 时间与质感 | 中断、最终状态与替代 |
| --- | --- | --- | --- |
| 打开/返回笔记 | 列表标题与该 note ID 的详情标题配对；内容面独立衔接。链接标记 note-open，返回按钮标记 note-return | 标题几何 540ms；旧内容 220ms 退出，新内容 540ms 停靠，位移 24–32px | 原生 Next/React ViewTransition 管理打断，不复制/持久化私人 DOM；浏览器历史采用真实标题配对和中性淡入，不猜测方向；直接进入无来源时使用后备过渡 |
| 列表恢复 | 数据范围可用后，在布局阶段恢复同一 URL 的滚动位置 | 恢复发生在新画面被采样之前，不等待动画 | pending 列表不读写滚动快照；保留搜索、归属与编辑器草稿；不新建历史栈 |
| 导航选中 | 指示底面读取实际选中链接几何，pending 与 committed 语义分开 | 340ms 移动；文本/图标约 160ms；侧栏宽度与工作区边距 360ms 协调 | CSS 连续反向，最新选中为准；ResizeObserver 清理；aria-current 仍来自已提交路由；强制颜色用轮廓 |
| 搜索面板 | 桌面从搜索入口的中心/顶部展开，手机从底部进入；标题、字段、结果保持清楚层次 | transform/clip-path 460ms 展开，240ms 收回，opacity 180ms；真实等待即刻可见 | CSS transition 从当前位置反向；Radix Presence 保留退出内容，快速重开保留输入；关闭后回到真实启动焦点，导航后不抢新焦点；手机不自动弹出键盘 |

所有动画支持 prefers-reduced-motion，运行中改变偏好也可落定；无原生 ViewTransition 时保留正常导航。动画不阻挡输入、路由或数据请求，不伪造保存/执行成功。不新增动画依赖。

## 验证范围

使用已有 E2E_MOBILE_HARNESS 门控中的 workspace-motion 合成场景，复用真实 AppShell、NotesWorkspace、NoteDocumentShell、NoteEditor 与搜索组件。场景将 UI 生产链接映射到门控路由，所有 API 读返回合成资料、所有写拒绝；映射不是生产鉴权或真实保存通过的证明。

检查目标包括 390/1440px、360/768px、短屏、长标题、键盘、手机抽屉、搜索成功/空态/失败、Escape/浏览器返回、快速开闭与导航、阅读/编辑切换、草稿、滚动和减少动态效果。截图与连续录屏只包含合成资料。实际覆盖、命令、结果与未验证项以日期验收记录为准，目标不代表已经通过。
