# 数据、来源、迁移与生命周期规范

状态：有效规范。维护日期：2026-10-14。适用范围：业务数据、关系、同步、派生内容、数据库和对象原件。权限细节见 [安全规范](security.md)。

## 模型与数据质量

业务表表达明确领域，不使用万能 `items` / EAV 代替实体。JSONB 可用于经过限定的事件、审计或外部元数据，不承载需要约束和关联的核心字段。

业务行具有可验证的 owner、稳定 ID、必要时间戳和归档语义。技术计数、队列、连接和追加版本表可采用专门结构，必须说明用途、最小权限与保留规则，不能为满足模板机械添加可误导的字段。

关系检查双方所有权；外键、唯一约束、检查约束和索引与写入规则共同设计。数据库约束承担最终完整性，不只依赖前端限制。

| 数据类型 | 规则 |
| --- | --- |
| 金额、数量与比例 | 明确币种、单位、精度、计算口径；零、未知与不适用分别表达 |
| 日期与时间 | 日期保留 DATE 语义；具体时刻使用可还原的 UTC instant；显示遵循用户 IANA 时区 |
| 文本与 Markdown | 原始内容与派生摘要分别保存；不在显示时悄悄改写原文 |
| 来源与事实 | 记录来源、观察时间与有效范围；事实、推测、建议分别表达 |
| 导入与批处理 | 先校验、预览影响、定义重复识别与失败恢复；保留导入来源和异常报告 |

时间转换遵循 [时间契约](contracts/calendar-time.md)。不采用服务器、浏览器或操作者所在时区作为未声明的业务默认。

## 权威源与派生物

| 领域 | 权威源 | 派生或缓存的边界 |
| --- | --- | --- |
| 任务 | Microsoft To Do | Supabase 缓存与 Today 引用不成为第二套完成状态 |
| 日程 | Outlook Calendar | 本地缓存、AI 提案和待执行队列不能冒充已写入 Outlook |
| 笔记 | Supabase 中原始 Markdown 与版本 | 编辑器状态、搜索索引、AI 摘要均可重建或核对 |
| 文件 | 私有 R2 原件；历史对象按元数据中的 provider 定位 | 元数据关联原件；封面、OCR、解析文本和摘要是派生物 |
| Career | 经核对的事实、版本和证据关系 | Bullet、答案、练习分析引用事实，不静默覆盖事实 |
| 投资 | 用户记录及可追溯来源 | 持仓账本、策略版本、回测和预测分别标注；不自动交易 |
| 运行状态 | 实际请求/执行结果 | 状态层只保留脱敏摘要；不复制业务正文作为新权威 |

完整状态语义见 [系统状态契约](system-status.md)、[文件架构契约](files/architecture-contract.md)。新增字段或系统接入必须明确权威方、同步方向、冲突处理和失效条件。

同步失败保留最近可读内容并标注陈旧/失败；失败不替换成“空数据”。离线或本地乐观状态仅表示等待确认，不得声称远端已成功。旧请求、旧 owner 或旧 revision 不能覆盖新状态。

## 迁移

1. 对照实际 schema、现有迁移和生成类型，说明新增约束与兼容策略。
2. 新增唯一版本的 migration；已部署迁移默认保持不可变，修正通过后续迁移表达。
3. 在隔离数据库验证干净重放、已有数据升级、权限、跨用户引用、失败与并发。
4. 提交并审查对应代码、类型、迁移与运行说明，确认目标项目及已有授权。
5. 按兼容顺序应用并记录实际迁移版本、部署提交、验证与恢复策略。

不得默认连接生产运行迁移。版本冲突先检查迁移历史与内容，不能直接改写生产 history 伪造一致。平台生成的实际版本应与仓库对齐并保留原因。

加字段优先兼容扩展；回填定义分批上限、事务范围、重试和核对。破坏性删字段、清空表、永久删除和重写原件需要明确对象及授权，事先完成恢复准备。

## 版本、审计与保留

履历事实、笔记和重要策略/答案等高价值内容按领域契约保留版本。恢复历史通过产生新的当前版本完成，不修改既有快照。并发写入核对 revision，冲突保留双方内容。

审计记录追加写，保存操作、目标、结果与允许的字段。秘密、恢复答案、正文原件和完整模型 payload 不得进入普通日志或审计。各表是否允许更新/归档按其契约，不把业务软删除规则机械应用于安全日志。

| 阶段 | 要求 |
| --- | --- |
| 创建与上传 | 元数据、字节、校验和、提交状态明确；pending 不等于已保存 |
| 修改 | 保留必要 revision/版本/审计，完成结果以权威写入为准 |
| 归档与恢复 | 默认列表正确过滤，关系与原件保留，恢复仍核对权限 |
| 导出 | 明确包含与排除项、格式版本、计数/校验和与原件范围 |
| 永久清除 | 单独核对对象与授权，检查关系、版本、缓存、备份和保留要求 |
| 保留期 | 按表/对象和用途登记；未确定前不新建自动清理任务或假定已清除 |

浏览器短期草稿不是备份，数据库备份不自动包含 R2 原件，Git 不保存业务数据库。恢复验证见 [系统备份](system-backup.md)。

## AI、事实与外发

开发 Agent 使用测试样本；应用内 AI 只接收 [AI 治理](ai-governance.md) 允许的上下文。文档或导入内容是数据，不是扩大工具权限的指令。

缺失事实保留为空或明确未知；不得为了展示完整而填入虚构个人经历、财务记录、评分或完成状态。展示合成数据时必须清楚标为测试，并与真实业务隔离。

验证：来源可追踪，单位/时间一致，重复导入与重试不产生重复副作用，跨用户读写与引用失败，恢复/导出能覆盖声明范围。
